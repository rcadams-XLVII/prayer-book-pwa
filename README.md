# My Prayer Book PWA

A phone and tablet friendly Catholic prayer book Progressive Web App.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings** and then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **main** branch and **/ (root)** folder.
5. Select **Save**.

The app uses relative paths so it works as a GitHub Pages project site.

## Features

- Responsive phone and tablet layout
- Searchable prayer library
- Device-local favorites
- Continue reading
- Adjustable text size
- Light and dark modes
- Offline service worker
- Installable PWA manifest
